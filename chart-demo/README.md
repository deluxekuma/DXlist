# maimai 譜面確認 Demo

這是一個獨立的 Web 版譜面確認原型，用於測試譜面解析、音符渲染與音樂同步。

## 測試網址

部署後可直接開啟：
```
https://deluxekuma.github.io/DXlist/chart-demo/
```

## 功能

- ✅ 從 lxns CDN 載入真實譜面資料
- ✅ 從 lxns CDN 載入真實音樂
- ✅ 基本 Tap / Break / Hold 音符解析
- ✅ 判定線與八個按鍵位置
- ✅ 音符從外向內移動動畫
- ✅ 播放 / 暫停
- ✅ 速度調整（0.5x ~ 2x）
- ✅ 進度條拖曳
- ✅ 時間顯示
- ⏳ Slide / Touch 等複雜音符（待實作）
- ⏳ 真實音符素材（目前用彩色圓形代替）

## 已知限制

- 目前只解析了最基本的 Simai 語法，複雜滑條、星星、Touch 等音符會被跳過
- 音符外觀使用 Canvas 繪製的彩色圓形，尚未使用 maimai 官方素材或 dxrating 的完整渲染
- 節奏解析為簡化版，BPM 變化與複雜拍號暫不支援
